# 지금 문 연 약국·응급실

내 주변에서 **지금 문을 연 약국**, **심야·공휴일 약국**, **응급실 실시간 가용 병상**을 한 화면에서
보여 주는 공공 서비스 웹앱입니다. 국립중앙의료원이 공공데이터포털에 공개한 오픈API를 씁니다.

> 생명이 위급하면 이 앱을 보지 말고 **119**에 전화하세요. 운영시간과 병상 정보는 기관이 입력한
> 값이라 실제와 다를 수 있습니다.

## 기능

- **위치 선택** — 브라우저 위치 권한으로 내 주변을 찾거나, 시·도와 시·군·구를 직접 고릅니다.
- **약국** — 가까운 순으로 보여 주고 "영업 중 · 22:00까지" 같은 배지를 붙입니다.
  - 조건: 지금 영업 중 / 밤 10시 이후 영업 / 공휴일 영업
  - 요일별 운영시간 펼쳐 보기, 전화 걸기, 지도 열기
- **응급실** — 응급실 일반·소아 가용 병상, 기준 병상 수, 병원이 정보를 입력한 시각.
  정원 초과(음수), 만실, 정보 없음, 1시간 넘게 갱신되지 않은 정보를 구분해 보여 줍니다.
- **데모 모드** — 서비스 키가 없으면 저장소의 예시 데이터(서울 종로구·중구)로 동작하고, 화면 맨 위에
  "데모 데이터" 안내를 띄웁니다.
- 한국어 UI, 모바일 우선 레이아웃, 키보드·스크린리더 접근성(탭, 상태 알림, 레이블), 다크 모드.

## 실행

Node 22 와 pnpm 12 가 필요합니다 (`corepack enable` 이면 `packageManager` 필드의 버전이 쓰입니다).

```bash
pnpm install
pnpm dev            # http://localhost:3000 — 키가 없으면 데모 모드
```

실데이터로 보려면 `.env.local` 에 서비스 키를 넣습니다.

```bash
cp .env.example .env.local
# .env.local 을 열어 DATA_GO_KR_SERVICE_KEY= 뒤에 키를 붙여 넣는다
pnpm dev
```

| 명령 | 하는 일 |
|---|---|
| `pnpm test` | 전체 테스트 (단위 + 컴포넌트 + 라우트) |
| `pnpm test:unit` | `src/lib` 단위 테스트만 |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm lint` | Biome 린트·포맷 검사 (`pnpm format` 으로 고침) |
| `pnpm build` / `pnpm start` | 프로덕션 빌드와 실행 |

테스트는 네트워크, 실제 시계, 실제 키 없이 돕니다. API 응답은 `fixtures/` 의 XML 을 쓰고, 현재 시각은
함수 인자로 넣습니다. 테스트 중 실제 `fetch` 를 부르면 바로 실패하게 막아 두었습니다.

## 공공데이터포털 서비스 키 받기

1. [공공데이터포털](https://www.data.go.kr)에 회원가입하고 로그인합니다.
2. 아래 **두 서비스**에서 각각 「활용신청」을 누릅니다. 둘 다 자동승인이라 신청 즉시 쓸 수 있습니다
   (반영까지 몇 분~1시간 걸릴 수 있습니다).
   - [국립중앙의료원\_전국 약국 정보 조회 서비스](https://www.data.go.kr/data/15000576/openapi.do) —
     상세기능 「약국 목록정보 조회」「약국 위치정보 조회」
   - [국립중앙의료원\_전국 응급의료기관 정보 조회 서비스](https://www.data.go.kr/data/15000563/openapi.do) —
     상세기능 「응급실 실시간 가용병상정보 조회」「응급의료기관 목록정보 조회」「응급의료기관 위치정보 조회」
3. 마이페이지의 개발계정 신청 내역(인증키 발급현황)에서 **일반 인증키(Decoding)** 를 복사해
   `DATA_GO_KR_SERVICE_KEY` 에 넣습니다. 공공데이터포털 인증키는 계정 단위라 두 서비스가 같은 키를 씁니다.

개발계정은 서비스당 하루 1,000건입니다. 서버가 응답을 캐시하므로(목록 1시간, 병상 1분) 소규모로는
충분하고, 공개 운영하려면 포털에서 활용사례를 등록해 운영계정 트래픽을 늘립니다.

키는 환경 변수로만 읽고 저장소에 넣지 않습니다. `.env*` 는 `.gitignore` 에 있습니다(`.env.example` 만 예외).

## 영업 중 판정

`src/lib/hours/` 에 있습니다.

- 시각은 서버 시간대와 무관하게 **한국 표준시**로 계산합니다.
- 오늘이 **공휴일**이면 요일 대신 공휴일 운영시간(`dutyTime8s/8c`)을 씁니다. 값이 없으면 쉬는 날로 봅니다.
- **자정을 넘기는 영업**(예: `2200`–`0200`, `1800`–`2600`)은 다음날 새벽까지 영업 중으로 봅니다.
  전날이 공휴일이었다면 전날의 공휴일 운영시간을 이어 받습니다.
- `0000`–`2400` 은 24시간 영업, `830` 처럼 앞자리 0 이 빠진 값도 받습니다.
- 한쪽만 있거나(`0900`–빈 값), 해석할 수 없거나(`09:3O`), 시작과 끝이 같은 값은 **확인 필요**로
  표시합니다. 잘못 "영업 중"이라고 안내하는 것보다 낫기 때문입니다. 운영시간이 한 칸도 없는 약국도
  "매일 휴무"가 아니라 확인 필요입니다.
- "심야"는 밤 10시를 넘겨 여는 날이 있는 약국, "공휴일 영업"은 공휴일 운영시간이 있는 약국입니다.

공휴일 표는 `src/lib/holidays/data.ts` 에 2026·2027년분이 있습니다(대체공휴일, 2026-06-03 지방선거,
2026년부터 공휴일이 된 노동절·제헌절 포함). 표에 없는 해가 되면 화면에 경고가 뜹니다. 매년 6월 무렵
우주항공청이 다음 해 월력요항을 발표하면 추가하세요.

## 구조

```
src/
  app/                 Next.js App Router — 페이지와 API 라우트(/api/pharmacies, /api/emergency)
  components/          화면 컴포넌트 (클라이언트)
  lib/
    api/               공공데이터 클라이언트, XML 파서, 캐시, 데모용 FixtureSource
    hours/ holidays/   운영시간 해석, 영업 중 판정, 공휴일 표
    geo/ time/         거리 계산, 한국 표준시
    model/             API item → 약국·응급실 모델
    services/          위치·지역 조회를 조합해 화면용 목록을 만든다
    http/handlers.ts   라우트 로직 (테스트에서 직접 부른다)
fixtures/
  docs/                공식 활용가이드의 응답 예제
  demo/                데모 모드용 예시 데이터
  errors/              오류 응답
docs/api.md            사용하는 API 엔드포인트·파라미터·필드와 출처
```

API 클라이언트는 `MedicalDataSource` 인터페이스 뒤에 있어서, 실서비스(`DataGoKrClient`)와 데모·테스트
(`FixtureSource`)가 같은 파서와 판정 로직을 거칩니다.

## 데이터 출처와 이용 조건

- 국립중앙의료원, 「국립중앙의료원\_전국 약국 정보 조회 서비스」, 공공데이터포털,
  <https://www.data.go.kr/data/15000576/openapi.do>
- 국립중앙의료원, 「국립중앙의료원\_전국 응급의료기관 정보 조회 서비스」, 공공데이터포털,
  <https://www.data.go.kr/data/15000563/openapi.do>

두 데이터의 포털 표기 이용허락범위는 **「이용허락범위 제한 없음」** 이고 비용은 무료입니다. 이 앱은 화면
하단과 이 문서에 출처(제공기관 국립중앙의료원, 공공데이터포털)를 밝힙니다. 공공누리 유형 표시가 붙은 데이터로 바꾸거나 추가하면 해당
유형의 표시 방법을 따르세요.

`fixtures/docs/` 의 XML 은 위 서비스의 공식 활용가이드에 실린 응답 예제를 옮긴 것이고,
`fixtures/demo/` 의 약국·병원 이름·주소·전화번호는 모두 지어낸 예시입니다.
